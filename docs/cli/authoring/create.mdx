title: facet create
description: Scaffolds a new facet project
---

## Usage

```sh
facet create [directory]
```

Creates a facet project in the given directory, defaulting to the current one. With no authoring flags it runs an interactive wizard; with any authoring flag it scaffolds directly in [headless mode](#headless-mode).

If `facet.json` already exists, the command asks before overwriting. `--force` skips that prompt.

## Examples

```sh
facet create                       # interactive wizard
facet create ./my-facet \
  --name my-facet \
  --description "What it does" \
  --skill greet --agent helper --command run
facet create ./bare --name bare --skill greet --no-readme
```

## Flags

<ResponseField name="--name" type="string" required>
  Facet name, required in headless mode. An unscoped slug or `@scope/name`. See the [name grammar](/specification/manifest#facet-name-grammar).
</ResponseField>

<ResponseField name="--description" type="string">
  Facet description.
</ResponseField>

<ResponseField name="--version" type="semver">
  Facet version. Defaults to `0.0.0`.
</ResponseField>

<ResponseField name="--private" type="boolean">
  Mark the facet private.
</ResponseField>

<ResponseField name="--skill / --agent / --command" type="repeatable">
  A text asset to scaffold. Repeat per asset. At least one is required in headless mode. Names are single segment, and a skill and command cannot share one.
</ResponseField>

<ResponseField name="--readme" type="boolean">
  Write and declare an editable `README.md`, seeded from the name and description. On by default. Use `--no-readme` to skip it.
</ResponseField>

<ResponseField name="--force" type="boolean">
  Overwrite an existing `facet.json`. Required in headless mode, which has no confirmation prompt.
</ResponseField>

<ResponseField name="--json" type="boolean">
  Emit a structured result: name, version, target directory, and the files written.
</ResponseField>

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Facet created. |
| `1` | Cancelled, declined overwrite, or invalid input. |
| `2` | An unexpected error escaped command handling. |

## Output

```
facet.json
README.md                    # unless --no-readme
skills/<name>/SKILL.md
agents/<name>.md
commands/<name>.md
```

Starter asset files are plain markdown with no front matter, because asset metadata lives in the manifest. You may add front matter later; the manifest still wins at install time. `README.md` and other [supplementary files](/specification/manifest#supplementary-files) are written verbatim.

## Details

### Headless mode

Headless scaffolding requires v0.24.0 or newer.

Passing `--name`, `--description`, `--version`, `--private`, `--skill`, `--agent`, or `--command` skips the wizard. `--force` and `--json` do not trigger headless mode on their own, so `facet create --json` alone still opens the wizard and prints no JSON document.

After scaffolding, validate with [`facet build --verify`](/cli/authoring/build) or make further changes with [`facet modify`](/cli/authoring/modify).

### Interactive wizard

The wizard asks for the name, description, version, and privacy, then the assets to scaffold. The README step is enabled by default and seeds content from the name and description, preserving your edits if you change either afterwards. A summary precedes any write.

## Troubleshooting

<AccordionGroup>
  <Accordion title="a facet already exists here">
    **Cause:** the target directory already contains a `facet.json`. Headless mode has no prompt to fall back on.

    **Fix:** pass `--force` to overwrite, or scaffold into an empty directory.
  </Accordion>

  <Accordion title="headless mode needs a name and at least one text asset">
    **Cause:** `--name` is missing, or no `--skill`, `--agent`, or `--command` was given. Scaffolding needs at least one text asset.

    **Fix:** supply both, for example `--name my-facet --skill greet`.
  </Accordion>

  <Accordion title="a name or version was rejected">
    **Cause:** the facet name breaks the [name grammar](/specification/manifest#facet-name-grammar), an asset name is not a single lowercase segment, or `--version` is not semver.

    **Fix:** correct the value. Names are validated, never normalized, so nothing is silently rewritten.
  </Accordion>
</AccordionGroup>
