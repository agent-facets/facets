---
title: facet search
description: Search the registry for published facets
---

## Usage

```sh
facet search [term]
```

Sends the term to the registry, which decides what matches and in what order. Without a term, lists published facets. At most one term is accepted, and more than one argument is an error.

## Examples

```sh
# Search for facets matching "plan".
facet search plan

# List all published facets.
facet search
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Search completed, including no results. |
| `1` | Failed, for example the registry was unreachable. |
| `2` | An unexpected error escaped command handling. |

## Output

```
Searching registry for 'plan'...found 2 matches.

viper-plans  v1.2.0 · by acme · 2 skills, 1 agent, 1 command
rezi         v0.5.0 · by julian · 3 skills, 1 server
```

Each result shows the facet name, latest version, author, and asset counts, including servers. Counts are omitted when all are zero. Only the first page of results is shown.

## Details

### Private facets in results

Signed out, you see only public facets. Signed in, results also include the [private facets](/private-facets) your account can access. Run [`facet login`](/cli/login) if a private facet you own is missing from the results.
