---
title: facet adapter remove
description: Remove an installed adapter
---

## Usage

```sh
facet adapter remove <name>
```

Deletes the adapter's directory under [`$FACET_DIR`](/cli/env)`/adapters/`. The adapter is not loaded first, so a broken or unsupported adapter can always be removed.

Removing an adapter does not delete the assets it already materialized into your project.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Adapter removed. |
| `1` | No adapter with that name is installed, or no name was given. |
| `2` | An unexpected error, such as a filesystem failure. |
