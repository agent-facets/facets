---
title: facet adapter remove
description: Remove an installed adapter
---

## Usage

```sh
facet adapter remove <name>
```

Removes an installed adapter by deleting its directory from the adapter base directory, `$FACET_DIR/adapters/` (see [environment variables](/cli/env) for the `FACET_DIR` layout).

## Exit codes

| Code | Meaning |
| ---- | ------- |
| `0`  | Adapter removed |
| `1`  | Removal failed (adapter not installed, filesystem error) |

## See also

- [`facet adapter add`](/cli/adapters/add) -- install an adapter.
- [`facet adapter list`](/cli/adapters/list) -- list installed adapters.
