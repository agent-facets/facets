---
title: facet adapter list
description: Lists installed adapters
---

## Usage

```sh
facet adapter list
```

Lists all installed adapters by scanning the adapter base directory, `$FACET_DIR/adapters/` (see [environment variables](/cli/env) for the `FACET_DIR` layout).

## Exit codes

| Code | Meaning |
| ---- | ------- |
| `0`  | Always — listed successfully, including an empty list |

## See also

- [`facet adapter install`](/cli/adapters/install) -- install an adapter.
- [`facet adapter remove`](/cli/adapters/remove) -- remove an installed adapter.
