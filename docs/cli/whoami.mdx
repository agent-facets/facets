## Usage

```sh
facet whoami
```

Resolves your credential, checking `FACET_TOKEN` before the saved [credentials file](/cli/env), and prints the identity it belongs to.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Identity displayed. |
| `1` | Failed, for example no credential, an invalid token, or a network error. See [`facet login`](/cli/login#troubleshooting). |
| `2` | An unexpected error escaped command handling. |

## Output

```
yourname <you@example.com>
  tier: free
  registry: https://api.agentfacets.io
  credential: FACET_TOKEN (environment)
```

The `registry` line always shows the base URL the identity was resolved against. The `credential` line appears when the token came from the environment rather than the saved file. A suspended account is reported as suspended.
