## Usage

```sh
facet whoami
```

Prints the verified identity for your selected credential. Selection follows [credential precedence](/cli/login#token-precedence), including browser sessions for the selected registry.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Identity displayed. |
| `1` | Failed, for example no credential, an invalid token, or a network error. See [`facet login`](/cli/login#troubleshooting). |
| `2` | An unexpected error escaped command handling. |

## Output

```
yourname <you@example.com>
  tier: free
  registry: https://api.agentfacets.io
  credential: FACET_TOKEN (environment)
```

The `registry` line shows the registry that verified the identity. The `credential` line is `FACET_TOKEN (environment)` for an environment token or `browser session` for browser sign-in; it is omitted for a saved personal access token. A suspended account is reported as suspended.

Browser sessions may be [renewed before this command completes](/cli/login#session-renewal). Authentication failures stop the command; they do not produce another identity or an anonymous result.
