---
title: facet list
description: List declared facets and their versions
---

## Usage

```sh
facet list
```

Shows all facets declared in `facets.json` for the current project. No network calls are made.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Listed successfully, including an empty project or no `facets.json` at all. |
| `1` | Positional arguments were given, or `facets.json` is malformed or declares an unsupported `manifestVersion`. |
| `2` | An unexpected error escaped command handling. |

## Output

Each facet is listed with the version [`facets.lock`](/specification/lockfile) resolved, or its source specifier when it has not been installed yet.

A malformed `facets.lock` is a warning rather than a failure: the listing falls back to source specifiers.

<Note>
  `facet list` reports facets and versions only. To see which contributions a project aliases or omits, read the `materialization` blocks in `facets.json`.
</Note>
