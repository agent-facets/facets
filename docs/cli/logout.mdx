---
title: facet logout
description: Remove saved registry credentials
---

## Usage

```sh
facet logout
```

Deletes the saved [credentials file](/cli/env). Removing a credential that was never saved is a no-op.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Credentials removed, or the file did not exist. |
| `2` | An unexpected filesystem error. |

## Details

### Revocation happens in the web UI

Logout makes no server call. It removes the local credential only, so the token itself stays valid until you revoke it at [agentfacets.io](https://agentfacets.io).

### FACET_TOKEN survives logout

If `FACET_TOKEN` is set, it keeps authenticating commands after logout, and the command says so.

```sh
unset FACET_TOKEN
```
