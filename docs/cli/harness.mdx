## Usage

```sh
facet harness <install|list|remove> [args]
```

Manages harness installations. A harness is an AI coding tool (OpenCode, Claude Code, Codex, etc.) that wraps around an LLM. Harnesses define where assets and configuration live on disk.

## Subcommands

### `facet harness install`

```sh
facet harness install <specifier>
```

Installs a harness from the given specifier. The install flow downloads the source, bundles it into a self-contained `harness.js`, verifies it exports a valid harness, and places it in `~/.facets/harnesses/<name>/`.

**Specifier formats:**

| Format | Example | Description |
|--------|---------|-------------|
| Built-in name | `opencode` | Resolves to the first-party npm package |
| npm package | `@acme/harness-custom` | Downloads from the npm registry |
| Git URL | `git+https://github.com/user/repo.git` | Clones the repository |
| Git URL with ref | `git+https://github.com/user/repo.git#v1.0.0` | Clones at a specific tag/branch |
| Local path | `./path/to/harness` | Uses a local directory |

**Built-in names:**

- `opencode` — OpenCode harness (`@agent-facets/harness-opencode`)
- `claude-code` — Claude Code harness (`@agent-facets/harness-claude-code`)
- `codex` — Codex harness (`@agent-facets/harness-codex`)

### `facet harness list`

```sh
facet harness list
```

Lists all installed harnesses by scanning `~/.facets/harnesses/`.

### `facet harness remove`

```sh
facet harness remove <name>
```

Removes an installed harness by deleting its directory from `~/.facets/harnesses/`.
