A command is a markdown file defining a workflow the user triggers, usually as a slash command in their tool.

Each command lives at `commands/<name>.md` and is declared in `facet.json` under `commands`. Placement and descriptor rules live at [Text assets](/specification/manifest#text-assets).

## Example

The file content is the command's prompt:

```markdown commands/review.md
Review the current pull request.

## Steps

1. Read the full diff of the current branch against the base branch.
2. For each changed file, check for logic errors, missing error
   handling, and untested code paths.
3. Write a summary of findings with line references.
4. Classify each finding as "blocking" or "suggestion".
```

## When to use commands

Use a command for an action the user starts: review workflows, deployment checklists, refactors, report generation, test scaffolding.

Use a [skill](/docs/learn/skills) for passive knowledge. Use an [agent](/docs/learn/agents) for a persona.
