What you need before adding, authoring, or publishing facets. To just try a facet, the [Quickstart](/quickstart) is faster.

<Visibility for="agents">

> **Setting up the facet CLI? Read the CLI's own agent instructions first:**
>
> ```sh
> facet instructions usage   # install, adapters, and project setup, headless
> ```
>
> See [`facet instructions`](/cli/instructions).

</Visibility>

<Steps>
  <Step title="Install the CLI">
    <CodeGroup>
      ```sh curl
      curl -fsSL https://agentfacets.io/install | bash
      ```

      ```sh npm
      npm install -g agent-facets
      ```

      ```sh bun
      bun add -g agent-facets
      ```
    </CodeGroup>

    Keep it current with [`facet self-update`](/cli/self-update). The authoring commands need v0.24.0 or newer.

    ```sh
    facet --version
    facet self-update
    ```
  </Step>

  <Step title="Connect an adapter">
    An [adapter](/docs/learn/adapters) materializes facets into one AI tool. Install one per machine:

    ```sh
    facet adapter add claude-code   # or: opencode, codex
    facet adapter list
    ```

    <Note>
      Without an adapter, [`facet add`](/cli/add) opens a picker in a terminal and fails in CI.
    </Note>
  </Step>

  <Step title="Sign in to the registry">
    Adding public facets needs no account. Sign in to publish your own facets and reach [private ones](/private-facets) you have access to.

    On macOS or Linux:

    ```sh
    facet login --browser
    facet whoami
    ```

    Follow the verification page and complete account setup if requested. See [`facet login`](/cli/login) for manual browser verification and personal access token entry on Windows.

    For CI and scripts, create a personal access token in your account settings at [agentfacets.io](https://agentfacets.io) and supply [`FACET_TOKEN`](/cli/env#facet_token). Do not run interactive login in CI.
  </Step>
</Steps>

## Verify your setup

```sh
facet --version        # CLI is installed and recent
facet adapter list     # at least one adapter connected
facet whoami           # signed in
```
