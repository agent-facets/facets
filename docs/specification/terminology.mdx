## Assets

  <Card title="Skill" icon="sparkles" href="/docs/learn/skills">
    `skills/<name>/SKILL.md` plus optional companions.
  </Card>
  <Card title="Agent" icon="bot" href="/docs/learn/agents">
    `agents/<name>.md`
  </Card>
  <Card title="Command" icon="terminal" href="/docs/learn/commands">
    `commands/<name>.md`
  </Card>
  <Card title="MCP server" icon="plug-zap" href="/docs/learn/mcp-servers">
    A keyed entry inside tool-owned configuration.
  </Card>
</CardGroup>

| Term | Definition | Reference |
| --- | --- | --- |
| Asset | One versioned contribution a facet ships. | [The facet artifact](/specification#the-facet-artifact) |
| Text asset | A skill, agent, or command, materialized as files. | [Text assets](/specification/manifest#text-assets) |
| MCP server declaration | Portable connection information: the one asset type that is not a text asset. | [Declarations](/specification/manifest#mcp-server-declarations) |
| Composed facet | A facet another facet declares as a dependency, not an asset. | [Fields](/specification/manifest#fields) |

## Files

| Term | Definition | Reference |
| --- | --- | --- |
| Supplementary file | A declared non-asset file that ships in the archive. | [Supplementary files](/specification/manifest#supplementary-files) |
| Companion file | A per-skill supplementary file that materializes with its skill. | [Supplementary files](/specification/manifest#supplementary-files) |
| Archive-only file | A top-level supplementary file that never lands on disk. | [Boundaries](/specification/install#boundaries) |

## Identity and names

| Term | Definition | Reference |
| --- | --- | --- |
| Facet identity | An unscoped slug or a scoped `@scope/slug`. | [Facet name grammar](/specification/manifest#facet-name-grammar) |
| Authored name | The name the publisher declared, which anchors every hash. | [Two identities](/specification/materialization#two-identities) |
| Effective name | The name a contribution is materialized under. | [Two identities](/specification/materialization#two-identities) |
| Version specifier | An exact version, wildcard, or `latest`. Ranges are rejected. | [Source grammar](/cli/add#source-grammar) |
| Source kinds | `registry`, `git`, or `local`. | [Source grammar](/cli/add#source-grammar) |
| Immutability | A published name and version never changes. | [Immutability](/specification/publish#immutability) |

## Integrity

| Term | Definition | Reference |
| --- | --- | --- |
| Canonical fingerprint | SHA-256 of the uncompressed inner tar, the trust anchor. | [Two hashes](/specification/integrity#two-hashes-two-domains) |
| Transport hash | SHA-256 of the uploaded bytes, a download check only. | [Two hashes](/specification/integrity#two-hashes-two-domains) |
| Canonical declaration fingerprint | The semantic identity of one MCP declaration. | [Fingerprint](/specification/manifest#canonical-declaration-fingerprint) |
| Build manifest | The integrity claim and per-entry hash map inside the archive. | [Outer layer](/specification/archive#outer-layer) |
| Integrity confirmation | The registry check required when a lockfile entry is written. | [Obligations](/specification/integrity#obligations) |

## Materialization

| Term | Definition | Reference |
| --- | --- | --- |
| Disposition | `authored`, `aliased`, or `omitted`. | [Dispositions](/specification/materialization#dispositions) |
| Override | Recorded `aliased` or `omitted` intent in `facets.json`. | [Recording intent](/specification/materialization#recording-intent) |
| Namespace | The space text asset types compete for names in. | [Namespaces](/specification/materialization#namespaces) |
| Collision group | Two or more contributions claiming one identity. | [Collisions](/specification/materialization#collisions) |
| Claimant | One member of a collision group. | [Collisions](/specification/materialization#collisions) |
| Stale override | An override naming something the resolved version dropped. | [Stale overrides](/specification/materialization#stale-overrides) |

## Install

| Term | Definition | Reference |
| --- | --- | --- |
| Desired set | Everything the project should have after this operation. | [Ordering](/specification/install#ordering) |
| Ownership record | Machine-local evidence of what was materialized, and the only authority for deletion. | [Ownership](/specification/install#ownership) |
| Tracked | An identity the ownership record covers. | [Ownership](/specification/install#ownership) |
| Untracked destination | A desired identity occupied by state nothing owns. | [Untracked destinations](/specification/install#untracked-destinations) |
| Declaration consent | Machine-local approval required before configuring a server. | [MCP configuration](/specification/install#mcp-configuration) |
| Frozen mode | Reproduce the lockfile exactly, never prompt, never write it. | [Frozen lockfile](/specification/install#frozen-lockfile) |

## Authoring and publishing

| Term | Definition | Reference |
| --- | --- | --- |
| Build | Producing the canonical archive from a source tree. | [Build](/specification/build) |
| Publish | Verifying that archive and uploading it. | [Publish](/specification/publish) |
| Content drift | Same name and version, different content. | [Drift](/specification/publish#when-the-built-artifact-has-drifted-from-source) |
| Identity drift | A different name or version. | [Drift](/specification/publish#when-the-built-artifact-has-drifted-from-source) |
| Review queue | A publish accepted but held for approval, which is a success. | [Review queue](/specification/publish#review-queue) |
| Server-only facet | A facet whose only assets are one or more server declarations. | [Declarations](/specification/manifest#mcp-server-declarations) |
