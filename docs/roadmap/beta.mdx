The open beta is the current phase. The [alpha](/roadmap/alpha) shipped the core author, publish, install, and update loop with MCP server configuration. The beta adds per-facet registry inspection and facet composition.

## Available functionality

- **Public facets.** Publishing, discovery, and installation remain free.
- **Personal private facets.** Private publishing is free during the beta.
- **Private facets for teams.** Paid access is available by request. See [Private Facets](/private-facets) to contact us.

## Planned functionality

### Facet composition

A facet that declares `facets: [...]` composes text assets from other published facets. The manifest accepts the field today, so a composing facet can build and publish, but the references are not resolved. [`facet add`](/cli/add) and [`facet install`](/cli/install) reject it before changing project state. Do not publish a composing facet until resolution ships.

## Planned commands

## Hardening

During the beta, we are tuning registry policy, settling the CLI surface, and closing documentation gaps. Review queues, name reservations, and private-publishing entitlements are already in place and continue to be calibrated.

See the [general availability](/roadmap/stable) criteria for what comes next.
