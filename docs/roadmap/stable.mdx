The stable release will be announced as **v1.0.0** and flags general availability. It ships when the [beta](/roadmap/beta) feature set has proven itself in public use.

## GA criteria

- **Beta features are shipped and stable**, including `facet info` and composition.
- **Format stability.** The facet manifest, `facets.json`, `facets.lock`, the archive format, and the adapter API are frozen under semver guarantees, so a breaking format change requires a major version. These are [independent version axes](/specification/install#version-axes), each with its own migration obligations.
- **CLI surface stability.** Commands and flags stop churning, and deprecations get a documented migration window.
- **Specification completeness.** The [specification](/specification) fully describes shipped behavior, suitable for independent implementations.

Progress is tracked in the [changelog](/changelog).
