The alpha is the current phase. The core loop of author, publish, discover, and install is live end to end against the public registry at [agentfacets.io](https://agentfacets.io).

## Shipped

- **Authoring.** Scaffold, edit, and package a facet with [`facet create`](/cli/authoring/create), [`facet edit`](/cli/authoring/edit), [`facet modify`](/cli/authoring/modify), and [`facet build`](/cli/authoring/build).
- **Registry.** Publish, discover, and authenticate with [`facet publish`](/cli/authoring/publish), [`facet search`](/cli/search), and [`facet login`](/cli/login).
- **Project management.** Add, install, update, remove, and inspect with [`facet add`](/cli/add), [`facet install`](/cli/install), [`facet update`](/cli/update), [`facet remove`](/cli/remove), and [`facet list`](/cli/list).
- **Platform.** First-party [adapters](/docs/learn/adapters) for Claude Code, OpenCode, and Codex, a public [adapter SDK](/reference/adapter-sdk), agent guidance via [`facet instructions`](/cli/instructions), and in-place binary updates with [`facet self-update`](/cli/self-update).

## Caveats

- Published versions are immutable, but registry policies such as review queues and name reservations are still being tuned.
- Breaking CLI changes may still ship between alpha versions. Check the [changelog](/changelog).

See the [beta goals](/roadmap/beta) for what is next.
