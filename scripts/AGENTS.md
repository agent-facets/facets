Keep the READMEs in this directory current when you change anything
here: `scripts/README.md`, `scripts/release/README.md`, and
`scripts/release-cli/README.md`. They carry the directory tree, the
release-pipeline walkthrough, and contract-level details that the
scripts themselves do not state — the pack-then-upload ordering, the
workspace-only-package rules, the changeset guard, and the adapter API
metadata injection. A reader should be able to understand the release
pipeline from those files alone.
